# Project instructions — Codex

Follow the global Codex instructions in addition to this project's rules.

## Before working
- Read `.agents/PROJECT.md` before making project-specific decisions or editing code.
- Inspect the actual relevant files, configuration and existing tests. Do not infer the stack or file contents.
- If a field in `.agents/PROJECT.md` is marked `PENDING`, do not assume its value; inspect the repository or ask.

## During work
- Respect established architecture and naming, and preserve working behavior.
- Keep changes minimal and within the requested scope; explain consequential trade-offs.
- Follow the project's documented checks. Do not claim tests ran unless they did.
- Do not commit, push, merge or change deployed resources without explicit permission, in accordance with global rules.

## Session handoff
- When asked for a handoff, summarize changed files, tests actually run, pending issues, and the exact next step.
## Session Continuity
- Read `.agents/SESSION.md` before continuing an existing development task.
- Treat undocumented progress as unverified.
- At the end of a development session, update `.agents/SESSION.md` with verified progress, decisions, tests, pending issues, and the exact next step.
- Do not update SESSION.md during read-only tasks.
